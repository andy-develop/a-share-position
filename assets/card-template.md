## 字段来源

| 位置 | 字段 | 说明 |
| --- | --- | --- |
| 页头 | `date` / `as_of_line` | 数据日期与"截至…收盘 / 盘中" |
| 01 | `temp` / `band` | 0–100 温度与七档名称；色带按 10/10/20/20/20/10/10 分段 |
| 01 右上 | `prev_temp` 差值 | 上一交易日为紧邻交易日写"较前日"，跨日写"较 MM-DD" |
| 01 右下 | `prev_date` `prev_band` `prev_temp` | 上一交易日温度参照 |
| 02 | `index_close` `chg_pts` `index_chg` | 点位、涨跌点数、涨跌幅 |
| 02 | `up` `down` `zt` `dt` | 涨/跌家数、涨停/跌停家数 |
| 02 | `volume_yi` `breadth_pct` `idx_avg` | 成交量（亿股）、市场广度、四指数均值 |
| 03 | `badge` `title` `desc` | 无信号｜买入信号｜卖出信号 + 四种固定标题与一句建议 |
| 03 | `grid` | 四格随状态切换，见下 |
| 04 | `b1_state` `b0_state` `exit_state` `exit_pill` | 已触发 / 未触发；离场原因高亮对应胶囊 |
| 05 | `commentary` | 点位、量能、涨跌家数、仓位状态四句自动文案 |

## 03 的四格随状态切换

| 状态 | 第一行 | 第二行 |
| --- | --- | --- |
| 持仓 / 建仓日 | 持仓状态 · 浮动盈亏 | 持仓成本 · 止损参考线 |
| 离场日 | 持仓状态 · 本笔盈亏 | 持仓成本 · 离场原因 |
| 空仓 | 空仓 · 建议仓位 0% | 最近离场 · 已空仓天数 |

## 版式规则

- 内容边距 40，右边界 746，正文宽 706。
- 章节序号 `01`–`05` 用朱红，标题用墨色粗体，右上角信息右对齐。
- 涨用红、跌用绿；`—` 表示无数据，不用 0 充数。
- 段落两端对齐，标点遵循避头尾（行首不出现标点）。
- 色带、刻度、三角形指针、胶囊均由代码绘制，不依赖外部图片资源。

## 纯文本兜底版

`--text` 或 `--no-image` 时输出等价文本，字段与上图一致，供不便看图的环境使用。
